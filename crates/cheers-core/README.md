# cheers-core

Contract surface for [cheers](../cheers/). Pure types and traits — `Claims`,
`Codec`, `UserStore`, `CredentialStore`, `RefreshStore`, and the typed error
hierarchy — shared between cheers's providers and downstream consumers
(mesofact, yah-platform, …).

No I/O, no platform code, no async runtime dependency.

See the design doc at `../../.yah/docs/working/cheers.md`.
